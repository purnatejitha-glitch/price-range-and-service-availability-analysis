# 🍽️ Price Range vs. Online Delivery and Table Booking

## 📌 Project Overview
This project analyzes the relationship between restaurant price ranges and the availability of online delivery and table booking services. It investigates whether higher-priced restaurants are more likely to provide these facilities.

## 🎯 Objectives
- Analyze online delivery availability across different price ranges.
- Examine table booking availability across different price ranges.
- Determine whether higher-priced restaurants are more likely to offer these services.
- Visualize service availability to identify patterns and trends.

## 🛠️ Tools & Technologies
- Tableau
- Excel
- Cognifyz Restaurant Dataset

## 📊 Analysis Performed
1. **Price Range Analysis:** Group restaurants by price range.
2. **Online Delivery Analysis:** Compare the availability of online delivery across price categories.
3. **Table Booking Analysis:** Examine table booking availability across price categories.
4. **Percentage Comparison:** Calculate the percentage of restaurants offering each service within each price range.
5. **Data Visualization:** Create stacked bar charts to compare service availability.

## 🔍 Key Insights
- Identify which price ranges have greater online delivery availability.
- Determine how table booking availability varies with restaurant price range.
- Evaluate whether higher-priced restaurants are more likely to offer online delivery and table booking.
